# Contratos

Este diretório contém os contratos públicos preservados pela refatoração.

- `openapi.yaml`: esqueleto do contrato HTTP e lista das operações existentes.

Antes da implementação, completar schemas, exemplos, status de erro e segurança a partir do comportamento real da API. Alterações intencionais devem ser propostas em uma spec separada; não devem entrar silenciosamente na migração de framework.
